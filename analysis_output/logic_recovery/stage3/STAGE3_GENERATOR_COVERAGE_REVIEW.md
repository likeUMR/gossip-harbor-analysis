## 从代码与配置反向核销，而非从已有网页统计覆盖

建立独立于网页目录的版本清单。资源、字节码原型、可读函数与匿名回调均须可互相对照。调用分析输出保守候选集合，对动态对象、继承、事件订阅和反射无法解析的位置明确登记，不能静默丢弃。

从 OnTap 同步路径继续追踪事件监听、状态存档及异步影响；同时纳入决定点击输入的初始化、每秒更新、配置重载、活动切换与资源消费入口。边界处标注读写、移交对象和继续追踪位置；不能见到公共函数或派发事件就停止。

每个函数内部按条件、提前返回、循环、状态写入、配置读取和事件派发分解为稳定逻辑单元。每个单元映射到四层文档中的具体段落和验证案例。一个页面可覆盖多个单元；一个跨模块机制也可引用多个页面。核销必须包含审核证据，函数名出现不能自动标为完成。

## 出口检查

| 检查面 | 必须提交的证据 | 放行条件 |
|---|---|---|
| 资源与原型 | 快照哈希、容器清单、原型与反编译对照、失败清单 | 范围内可执行资源均核销；缺失项明确阻断受影响结论 |
| 入口与调用 | 同步调用、事件监听、动态候选、定时与初始化关联 | 未归属入口、未解析且影响行为的调用为零 |
| 函数与分支 | 独立生成的逻辑单元清单，逐项对应解释、证据、审核状态 | 相关函数和分支全部核销；排除项有理由和证据 |
| 状态与生命周期 | 每个字段的读、写、存档、重载、清除、重置和作用域 | 未解释的状态变更与生命周期缺口为零 |
| 配置与变体 | 装载顺序、活动/账号/等级选择、字段消费者、实际行与边界 | 每个读取字段有语义与来源；每个可选配置行有归属；远端未知单列 |
| 文档与导航 | 逻辑单元至页面段落映射，父层顺序、子层解释与叶层算法检查 | 漏页、不可达页、只有名称无解释、上下层矛盾为零 |
| 行为验证 | 控制随机输入、时间边界、状态前后差分、存档重载、事件顺序 | 每个可行分支有区分性案例；关键组合与原版差异已处理 |

验证配置不能只取一个代表母体：按不同算法及条件建立等价类，同时机械核对全量配置行。等级交界、活动重载、连续与免费资格重叠、Lucky 与 Disco 优先级、能量增益与次数消耗等需专门验证，不能仅用两两组合覆盖率放行。
