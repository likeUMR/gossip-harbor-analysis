# 用户差异与配置分层

参考 PDF 的第四部分补齐“为什么不同玩家看到的订单、活动和付费内容不同”的统一模型。差异来自三层：服务器选择的客户端配置、账号进度与近期行为、当前随机结果。

## 三层差异

| 层 | 客户端可见输入 | 影响 |
| --- | --- | --- |
| 配置选择 | `FileReplace` 文件名/后缀、活动直接下发内容、`general_conf_new` 开关和倍率 | 改变订单难度、生产内容、泡泡、商店、剧情消耗、活动棋盘和礼包投放 |
| 账号数据 | 玩家等级、解锁进度、订单历史、当日累计难度分、购买进度、活动状态 | 同一配置下也可能得到不同订单档位、礼包序列和活动入口 |
| 随机结果 | 权重池、无放回产出池、订单物品抽取、活动奖励抽取 | 产生同一条件下的具体物品、奖励和出现时机差异 |

## PDF 归纳的 18 类包内变体

1. 主棋盘物品与购买价格：合成链、母体产物、泡泡参数、购买价格。
2. 幸运产出与生产助力：适用母体、幸运产物、额外产出参数。
3. 普通订单规则：难度区间、适用阶段、需求项数权重。
4. 订单物品价值：解锁、金币、难度分、库存推荐参数。
5. 订单辅助内容：宝箱订单、引导订单、顾客头像。
6. 商店：日常商品候选、标价和各位置权重。
7. 卡牌棋子：出现概率和生成种类权重。
8. 飞机奖励与操作积分：飞机奖励、合成、买泡泡、商店购买积分。
9. 主线剧情：任务序列、金币消耗、奖励和展示信息。
10. 预告与通知：功能预告条件和回流文案。
11. 对战模拟对手：对手分段得分进程。
12. 冒险合成棋盘：布局、迷雾、区域开放、母体产出和奖励。
13. 农场活动棋盘：障碍、扩展、奖励容器和产出。
14. 多棋盘阶段活动：布局、障碍、产出和转盘代币。
15. 纯合成活动棋盘：迷雾、布局、产出和部分体力消耗。
16. 地图探索：清障消耗、清障产物和关联棋盘内容。
17. 挖矿活动：矿区布局、矿物和奖励容器产出。
18. 破障玩法：特定主题初始棋盘物品修订。

当前站点的母体、合成、订单、付费和活动页面已经覆盖这些类别中的源码入口和本地配表；本清单作为 PDF 对照分母保留，账号真实后缀和服务器投放仍是外部缺口。

## 三种服务器控制方式

- 文件替换：服务器下发 `FileReplace` 后缀，客户端按精确文件名优先装载包内变体，失败才回退默认。
- 直接下发活动内容：活动时间、等级门槛、任务、阶段、商品、奖励等内容由活动 payload 提供。
- 通用参数：`general_conf_new` 提供开关、模式、倍率和规则标签，决定客户端走哪个分支。

活动基础状态按服务器时间和 `sLv/sTime/eTime/rTime` 判断：未开始、进行中、结束保留、释放。礼包、通行证和专用活动随后读取自己的任务、阶段和奖励配置。

## 参考示例

- `shopitem_flashsale=1` 时，随机选品加入当前需求和上一轮购买反馈修正；值为2时先尝试需求相关选品，失败才随机兜底；其它值走未加入模式1修正的随机路径。
- `levelupGift` 按 `商品序列[CurIndex]` 取当前商品，截止时间为服务器当前时间加 `duration`，购买成功后 `CurIndex + 1`；因此同等级玩家也可能看到不同商品。
- 通行证读取 `battlePassReward`、`battlePassDailyTask`、`battlePassMoreTask` 和 `battlePassExtraReward`，等级行的 `require/reward/golden_reward` 分别参与进度和普通/高级奖励。
- `bubbleDecreaseConfig` 按未购买泡泡的登录天数调整概率倍率；`taskGoldCostConfig` 按标签、等级和当前金币调整剧情成本；`energy_boost_cost` 提供生产倍率消耗序列。

PDF 中的变体示例也保留：`hard` 可把1105解锁等级从9改为15，`nerf` 可把1303金币从8改为7，`nerf_more` 可改为6。它们说明的是同一客户端如何因后缀改变数值，不代表当前账号必定使用这些后缀。

## 玩家数据与两个可复刻公式

玩家差异还来自账号和运行状态字段：账号来源包含 `userId`、`install_id`、版本、渠道、地区、语言、广告/网络/追踪来源；成长包含等级、经验、主线、地图、解锁和活动阶段；资源包含金币、红钻、体力、棋盘、仓库、缓存物品、订单和 `orderMeta`；购买包含商店上一轮购买、礼包序号、未购买泡泡登录天数、累计付费和 `month_pay`；活动包含 `activity_data`、`bundle`、弹窗次数、冷却、有效期和购买序号；操作日志包含支付、合成、生产、订单动作、资源收支和设备/网络环境。复刻差分时必须先固定这些字段，不能只固定等级。

同为等级 40、同为 Random3，PDF 示例中当日难度分 1800 的玩家第一项为 8-10 级、第二项上限 7 级；难度分 2200 的玩家第一项为 9-10 级、第二项上限 8 级。该例证明“同配置”不等于“同订单”。

未购买泡泡天数 `D`：跨自然日成功登录才 `D += 1`，同日不增加；成功解锁非免费且消耗大于 0 的泡泡后清零；长时间离线回来只加 1。配置门槛升序时选择严格小于 `D` 的最大门槛，倍率为 `ratio / 100`；例如门槛 3、比率 50 时，`D=3` 不生效，`D=4` 生效为 0.5。最终概率还要乘基础概率、物品资格、棋盘空间和其它修正，并受 1% 下限影响；功能关闭、配置为空、`D<=0` 或无匹配时倍率为 1。

升级礼包的复刻变量为升级后等级 `L`、触发等级集合 `T`、有效连续非空商品序列 `G=(g1,...,gN)` 和购买序号 `k`（初始 1）。配置存在且 `L∈T` 时取 `gk`，若 `1<=k<=N` 否则回到 `g1`；礼包内容为当前项，购买成功才令 `k后=k+1`，未购买保持不变。玩家甲已买 A、序号为 2 时下次取 B；玩家乙未买 A、序号为 1 时取 A；服务器换发新序列时可能将序号重置为 1。上述公式是可复刻的序号规则，商品实际内容仍取活动 payload。
