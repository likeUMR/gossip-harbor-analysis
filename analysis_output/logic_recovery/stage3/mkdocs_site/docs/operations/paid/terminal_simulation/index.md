# 主棋盘终局模拟：完整历史归档

本页归档旧版终局模拟。它覆盖三类钻石策略、30 个固定种子、累计金币与主线推进、最终库存和剧情日明细。模拟用于研究策略差异，不等同于原版客户端实测。

## 模拟设定

| 项目 | 设定 |
| --- | --- |
| 时间 | 第 1 天 10:00 开始；每天 10:00–19:00 整点上线 |
| 初始状态 | 金币 0、体力 100、普通库存为空；所有 Series、订单槽、商店、气泡开局解锁 |
| 棋盘与母体 | 棋盘/库存无限；每个 Series 拥有最高级母体 |
| 剧情目标 | 主线 4,192 项、287 个剧情日；累计金币需求 1,551,042 |
| 运行规模 | 三类策略各 10 个固定种子，共 30 局；种子为 `2026092701`–`2026092710` |
| 时间与操作 | 体力每 120 秒恢复 1；主动操作平均 1.27 秒 |
| 订单生成 | 只生成 Random1–5 和 Baseline；最后一个 Filter 固定生效；CD 到期需补位扫描，不自动补单 |

## 三类钻石策略

- **0 氪**：每天首次体力耗尽时花 10 钻。
- **中氪**：每天前三次体力恢复分别花 10、20、40 钻。
- **顶氪**：按 10、20、40、80、160 钻递增，之后每次 160 钻，并加速母体。
- 三类策略都不花钻刷新商店；模拟没有设置钻石来源、余额或预算上限。

## 输出与知识点

- 累计金币与主线完成次数交互图。
- 三类玩家的典型一天、钻石消耗构成和 30 局结果。
- 每类 10 局汇总、每局最终库存和完整单局明细。
- 剧情金币按 287 个剧情日分布、日明细和任务金币查询。
- 运行版本标记为 `Gossip Harbor 3.98.10 local Lua_Config snapshot`，生成工具为 `tools/run_terminal_simulation.py`，并记录 `known_approximations`。

## 如何解释结果

每类只有 10 个固定种子，极差不是置信区间；无限棋盘、全内容解锁、无钻石预算和固定上线时间都会影响结果。模拟只能回答“在这些规则和假设下三类策略如何表现”，不能证明真实服务端概率、经济值或客户端所有边界。
