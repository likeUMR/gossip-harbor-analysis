# 奖励分组与快照

根据宝箱顾客前缀拆分奖励，普通部分马上发，标记部分稍后发。两份都复制，确保完成消息展示的是提交时的结果。

## 内部处理顺序与目的

1. 按宝箱标记前缀把奖励拆成即时与延迟两份。

2. 复制两份作为交付快照，避免之后重新取奖改变显示结果。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：即时奖励和宝箱标记分离

**本例情境：** 本次奖励同时包含8金币和一个合法宝箱顾客标记。

**判断与目的：** 前缀识别把标记留给稍后处理，分别复制两份快照。

**玩家看到的结果：** 先领取8金币；宝箱标记暂留在延迟结算中，不被当成金币或直接一件棋子。
