# 特殊任务确认

特殊窗口先把最多三个需求图像聚到中央，动画初始化之后点击遮罩才提交。它先选独立棋盘对象，没有对象时用仓库图像表现；这一选择不是普通需求扣除算法。

## 内部处理顺序与目的

1. 选独立棋盘物作展示，没有对象时使用仓库图像。

2. 等待初始化和聚拢表现完成，期间忽略遮罩点击。

3. 再次点击恢复原视图并提交，随后播放仓库补交表现和关闭窗口。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：特殊订单二次点击

**本例情境：** 任务1的需求物展示已准备完成，玩家再次点击窗口。

**判断与目的：** 先展示需求，再由玩家再次点击确认提交，不沿用普通订单仓库窗。

**玩家看到的结果：** 首次点击只看到任务物聚拢；第二次点击完成任务1，按任务表领15宝石和100能量，余额变35宝石、110能量。
