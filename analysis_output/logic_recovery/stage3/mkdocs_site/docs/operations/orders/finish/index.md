# 模型收尾，再播放交付表现

所属模型补位与全局完成通知返回后，主棋盘再刷新状态、按资格发首轮微笑提示，检查同步并派局部完成消息。视图收到消息播放棋子飞入、奖励表现和顾客离开；表现不能再次发放已经落账的奖励。

## 本阶段的判断与处理顺序

1. **再次刷新、提示与同步消息**：全局OrderFinished先于棋盘局部FinishOrder；同步上传检查夹在局部消息之前。首轮微笑提示只在先前资格满足时派发。

2. **扣物飞行、奖励表现与顾客离开**：材料先在模型中删除，视图再播放飞行动画。普通奖励先表现，相册和礼物稍后表现，顾客最后离开并移除格子。特殊与分支则用各自完成动画。

## 演示案例

下面分别改变前提，让各条分支实际发生；互斥结果属于不同场景。

### 场景1：首轮提示与完成消息

**本例情境：** 三件材料已扣、8金币已发，本单符合首次微笑提示条件。

**判断与目的：** 先处理所属模型全局完成通知，再刷新、发首轮提示、检查同步，最后交视图。

**玩家看到的结果：** 金币108、三件物品已扣；玩家看到首轮微笑提示，随后进入交付表现，同步检查不会再发8金币。

### 场景2：材料飞入后顾客离开

**本例情境：** 结算已完成，两件棋盘203和一件仓库204准备播放飞入表现。

**判断与目的：** 先播放三件材料飞入，再展示已到账金币，最后移除顾客并恢复滚动。

**玩家看到的结果：** 看到两件203和仓库204依次完成需求，8金币飞入后顾客离开；余额保持108，不会变116。
