# 剧情与好感度系统

参考 PDF 的第三部分补充到订单体系：好感度订单不是普通金币单的换皮，而是把订单价格转换成礼物，再由角色好感度模型处理等级、剧情、回礼和角色解锁。

## 处理链

好感度开放且随机好感度订单开放后，槽位10的创建器才允许建单。订单最多三项需求，完成时不发普通金币，而是根据订单价格总和抽取礼物数量；订单创建阶段会把礼物奖励快照写入订单，完成阶段再由亲密度模型领取。订单奖励页面已记录“亲密度随机单不发基础金币”的分支，本页补齐其后续养成影响。

## Olivia 参考进度

PDF 给出的 Olivia 示例保留为参考基线：1级奖励体力30；2-4级解锁角色剧情；5级剪刀1；6级角色 moment；7级存钱罐1；11级绿色挑选箱1；12级欢迎礼物箱1。这里的等级和奖励是参考 PDF 的内容快照，不声明为当前账号或所有版本的有效配置。

## 每日回礼和角色解锁

每日回礼先按参与角色的好感度等级加权抽角色，角色概率为：

`P(角色 c) = 角色 c 的好感度等级 / 全部参与角色等级之和`

选中角色后，再从该角色当前等级的回礼池抽奖；等级越高，回礼池的平均价值可以更高。角色之间也存在前置关系，PDF 示例为 Harrison 需要剧情到第12天且 Quinn 好感度达到3级，Sam 需要剧情到第20天且 Quinn 好感度达到10级。因此好感度既是订单奖励出口，也是角色内容和后续角色开放条件。
