# 加速刷新

移动可能改变加速棋子的覆盖，所以移动完成后立即刷新计时组件。随后通知移动结束并返回；这次拖动的合成、吞噬和交换均不会执行。

## 本机制怎样执行

是否涉及计时或激活加速组件 → 有则立即刷新计时 → 发移动结束 → 返回。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：移动正在计时的母体

**本例情境：** 玩家移动可受加速影响、仍在计时的母体到空格。

**判断与目的：** 母体移动可能改变加速覆盖，因此马上刷新计时组件，再结束移动。

**玩家看到的结果：** 母体到达新格，计时显示按新位置重新核对；本次不合成，也不额外生成物品。
