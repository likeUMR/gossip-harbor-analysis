# 合成通知与邻格震动

新物已经写入棋盘后，先通知合成，再震动目标周围四个正交邻格。可解锁纸箱会在震动中消除，并可能腾出空间；这些变化发生在副产物判断之前。 合成通知还会让已开启的活动读取源物分数、更新任务，或检查新物解锁；这些响应发生在主棋盘后续副产物判断之前。

## 本机制怎样执行

新物已写入 → 局部合成通知 → 全局同步响应 → 四邻格组件处理 → 震动通知 → 返回普通追加结算。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：邻格接收合成震动

**本例情境：** 201合成202，目标周围还有三个有物品的正交邻格。

**判断与目的：** 先通知合成，再只震动上下左右邻格。

**玩家看到的结果：** 目标出现202，三个仍有物品的正交邻格收到震动，斜角格没有震动；本例没有额外掉落。
# 合成通知

合成完成后先有棋盘局部 `MergeItem`，再有全局 `ItemMerged`，随后才处理邻格震动。全局事件的消费者各自拥有资格、上限、落库和联网条件；详见[具体算法与状态闭包](detail.md)。
