# 拖拽收尾

模型处理结束后，松手函数仍会完成界面收尾：选中当前结果、刷新信息栏和可交付格，通知释放，清拖动缓存并重启提示。模型提前返回只是结束动作分派，不等于这一整次玩家输入已经不再触发任何界面逻辑。

## 判断与分支（按触发位置）

1. **选中与释放**：空位移动通常继续选原对象；合成后原对象消失则选目标格结果。最后根据物品是否消失或位置是否变化决定收集提示，发送释放事件并清理拖拽状态。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：合成后的选中收尾

**本例情境：** 201合成202后，原拖动对象已被删除，界面准备结束拖动。

**判断与目的：** 优先看原对象还在不在，不在则选择落点的结果物，然后释放拖动状态。

**玩家看到的结果：** 202成为当前选中棋子，拖动结束，信息栏显示结果物而非已删除的201。
