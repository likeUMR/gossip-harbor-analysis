# 坐标与对象校验

先排除棋盘外落点，再核对源格对象。如果拖动期间源格被替换，旧棋子的拖动也会被拒绝。这两项先于读取目标棋子，防止过期输入继续执行。

## 本机制怎样执行

目标坐标合法 → 源格仍是原对象 → 读取目标棋子；失败直接复位。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：拒绝过期拖动对象

**本例情境：** 拖动期间原201被同类型新对象替换，玩家仍在释放旧对象。

**判断与目的：** 格子内的物品身份与拖动对象不同，拒绝继续。

**玩家看到的结果：** 旧拖动被撤回，棋盘上的新201和目标棋子都保留，不消耗物品。
