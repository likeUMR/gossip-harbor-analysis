# 剪刀次数合并

目标也是剪刀时，不打开拆分确认窗；两把剪刀合成一把，其次数为两者剩余次数之和。它保留使用量，不把次数恢复成默认值。

## 本机制怎样执行

确认双方都是剪刀 → 读取剩余次数 → 消耗两旧对象 → 创建新剪刀并保存合计次数 → 合成通知。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：两把剪刀合并次数

**本例情境：** 玩家把一把剩两次的剪刀拖到另一把剩三次的剪刀上。

**判断与目的：** 同类剪刀不拆分棋子，直接合并剩余使用次数。

**玩家看到的结果：** 两把剪刀变成一把可使用5次的剪刀，源格空出。
