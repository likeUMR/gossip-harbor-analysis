# 升级与剪刀

有目标时，先判断拖入物能否对目标产生特殊作用。升级道具和普通剪刀通常弹确认窗；窗口已打开就结束当前拖拽，确认后再复核资格并执行。两把剪刀则直接合并剩余次数。

特殊作用没有接管时继续普通合成。特殊物不能作用会先给失败提示，但提示本身不阻断后续合成、吞噬或交换。

## 判断与分支（按触发位置）

1. **道具目标资格**：资格由目标配置决定：目标是否允许被升级或拆分。剪刀对普通目标还要求棋盘有空位；两把剪刀合并次数例外，不受这个满盘限制。
2. **道具升级**：升级道具把目标替换为其配置下一等级，消耗一件升级道具。等待确认时道具回原位；取消不执行替换。该路径有合成通知和邻格震动，但不经过普通合成的副产物流水线。
3. **剪刀次数合并**：目标也是剪刀时，不打开拆分确认窗；两把剪刀合成一把，其次数为两者剩余次数之和。它保留使用量，不把次数恢复成默认值。
4. **剪刀拆分**：剪刀作用普通目标时，将目标拆为两件同链前一级物品，消耗一次剪刀次数。第一件放在目标原格，第二件按周围空位顺序放下；剪刀次数耗尽才删除。
5. **道具作用失败**：特殊物不满足目标资格时显示原因，但仍继续合成资格检查。弹出确认窗与显示失败提示的控制流不同：前者接管拖拽，后者通常继续。

## 演示案例

下面分别改变前提，让各条分支实际发生；互斥结果属于不同场景。

### 场景1：剪刀获准拆分202

**本例情境：** 玩家用剪刀作用于允许拆分的202，棋盘有空格。

**判断与目的：** 目标允许拆分且有空间，特殊作用先接管拖拽。

**玩家看到的结果：** 出现拆分确认窗，202暂未改变；确认后才能得到两件201。

### 场景2：升级202到203

**本例情境：** 玩家把升级道具拖到202，并确认使用。

**判断与目的：** 玩家确认后消耗升级道具，把目标提升一级。

**玩家看到的结果：** 升级道具消失，202变成203；不执行普通合成直接计分和副产物抽取，能量不变。

### 场景3：两把剪刀合并次数

**本例情境：** 玩家把一把剩两次的剪刀拖到另一把剩三次的剪刀上。

**判断与目的：** 同类剪刀不拆分棋子，直接合并剩余使用次数。

**玩家看到的结果：** 两把剪刀变成一把可使用5次的剪刀，源格空出。

### 场景4：最后一次剪刀拆分

**本例情境：** 玩家确认用只剩一次的剪刀拆分202。

**判断与目的：** 扣剪刀次数，再把目标拆成两件前一级食物；第二件按固定空位顺序放下。

**玩家看到的结果：** 剪刀消失，原202变成两件201，分别在原目标格和原剪刀格；能量不变。

### 场景5：升级被拒后交换

**本例情境：** 升级道具遇到不可升级、但可移动且没有其它作用关系的目标。

**判断与目的：** 显示不能升级的提示，但继续判断后续分派，最终走交换。

**玩家看到的结果：** 没有消耗升级道具，两件物品互换位置；玩家先看到不可升级提示。

LevelUp 将目标替换为 `MergedType`；LevelDown 拆成两个前一级棋子；ItemSwallow 按两个 `Swallow_Weight` 生成目标代码并保存进度，两个目标数量都达标才 Transform；吞噬扫描按有效棋盘位置顺序，不随机打乱。

## 贯穿案例：两个 201 合成 202


拖动 201 到另一个 201：两个输入被消耗，目标格变为 202，源格腾空。本地映射 201.MergedType=202，结果 202.BubbleChance=0，所以本例不会产生普通气泡；特殊棋子分支也未执行。坐标与动画未有运行时回放。
