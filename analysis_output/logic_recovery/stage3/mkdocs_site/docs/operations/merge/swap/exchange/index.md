# 位置交换

目标可移动时，先交换格层，再分别更新位置和移动日志，刷新加速。棋子对象与组件不重建，因此不会重置母体次数或计时。

## 本机制怎样执行

目标可移动 → 三次写格完成交换与订单刷新 → 两条日志 → 更新双方位置 → 刷新加速。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：不同类型棋子互换

**本例情境：** 可移动的201拖到可移动的204，两者没有合成或其它作用关系。

**判断与目的：** 前面各作用未接管，沿用两件原对象交换格子，再刷新计时影响。

**玩家看到的结果：** 201和204互换位置，物品总数不变、能量仍10；不生成新物，也不发空格移动专用的结束通知。
