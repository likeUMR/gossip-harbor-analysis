# 棋子交换

特殊作用、合成与吞噬都没接管，才检查目标可移动性。目标不能移动则拖入物复位；能移动则两件棋子交换位置，保留对象、类型和各自内部状态。最后处理移动加速，返回界面收尾。

## 判断与分支（按触发位置）

1. **交换资格**：到最后兜底仍不能合成或吞噬，目标被纸箱、蜘蛛网、锁定或吞噬点击限制固定时，不允许交换。拖入物回原格，不消耗双方。
2. **位置交换**：目标可移动时，先交换格层，再分别更新位置和移动日志，刷新加速。棋子对象与组件不重建，因此不会重置母体次数或计时。

---

## 演示案例

下面分别改变前提，让各条分支实际发生；互斥结果属于不同场景。

### 场景1：锁定目标拒绝交换

**本例情境：** 201拖到锁定的204，前面的特殊作用、合成和吞噬都不能接管。

**判断与目的：** 最后检查目标能否移动，锁定物不能互换。

**玩家看到的结果：** 201回原格，锁定204保持原位，没有扣能量或合成。

### 场景2：不同类型棋子互换

**本例情境：** 可移动的201拖到可移动的204，两者没有合成或其它作用关系。

**判断与目的：** 前面各作用未接管，沿用两件原对象交换格子，再刷新计时影响。

**玩家看到的结果：** 201和204互换位置，物品总数不变、能量仍10；不生成新物，也不发空格移动专用的结束通知。
