# 产物落子

最终代码和落点已确定、次数与实际能量处理完成后，创建新棋子并保存，写入目标格，再刷新订单状态。随后通知棋盘和活动；符合资格的活动可能复制物品、累计进度或发奖励。通知完成后记录本次产出，再回到点击收尾检查母体变换、销毁和CD辅助。

这里按“创建→写格与订单刷新→通知及其同步响应→日志→返回收尾”的实际顺序解释。各活动独立判断资格，并非每次点击都会触发全部活动；通知还可同步引出追加落子。
