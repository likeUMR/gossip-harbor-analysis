# Week9：游玩节奏与母体 42 次轮询

本页把 Week9 PDF 第 1-4 页的体验记录接回“母体点击”。它是参考分析和实测样本，不替代客户端源码；数值用于复刻测试输入，不能直接当成所有账号的固定规则。

## 一次游玩的可复刻记录

PDF 记录了普通 16 级玩家、购买战令后的首次游玩，以及首日体力消耗。体力来源包括教学赠送、体力瓶、升级、解锁格子、签到、钻石购买和活动奖励。一次普通游玩约 10 分钟，首日或战令后约 30 分钟。连续消耗体力却没有订单、剧情或升级反馈时，体验转为无聊；订单完成、金币/经验/笑脸和升级反馈密集时，体验转为爽快。复刻时应同时记录：起始等级、能量来源、每次点击、产物、合成、订单完成、金币、经验、笑脸、升级和剩余能量。

## 42 次母体轮询模型

示例产出袋包含 35 份一级面包、2 份二级面包和 5 份一级土豆。二级面包折算为两个一级单位，因此主链等价量为 `35 + 2×2 = 39`，副链为 `5`，总轮询数为 `42`。

| 项目 | 计算 | 结果 |
| --- | --- | ---: |
| 主链长期平均 | `39 / 42` | `0.929` 次/轮询 |
| 副链长期平均 | `5 / 42` | `0.119` 次/轮询 |
| 副链独立抽样期望 | `42 × 5/42` | `5` |
| 副链独立抽样标准差 | `sqrt(42p(1-p))` | 约 `2.10` |
| 一次都不出副链 | `(1-5/42)^42` | 约 `0.488%` |

这说明固定 42 次轮询能保证长期数量，短期仍有波动。副链会暂时占格并延迟主链，但之后可被订单消耗，形成“等待/惊喜”的节奏；高级副产物由 `BaseLineOrderSlot` 消耗。不要把“42 次固定轮询”误写成每次独立抽样：前者是配置/产出袋约束，后者只是用于估计坏运气的反事实模型。

## 复刻检查表

1. 固定同一母体、等级、棋盘空位和订单缺口，记录 42 次轮询的每个物品及一级等价量。
2. 分离主链、副链和高级副产物，检查产出袋是否无放回、何时重装以及次数/储备如何保存恢复。
3. 在能量不足、棋盘满、Lucky/活动覆盖和配置变体下重复记录；这些条件不能用平均值代替。
4. 把产物落点、订单消费、金币/经验/笑脸和下一次母体状态作为同一条链核对。

**证据标记：** 42 次样本和体验时长为 `runtime-pending` 的参考观察；母体点击的状态、空位、能量、Lucky、普通产出和保存恢复以本目录下的源码页面为 `source-confirmed` 或其页面标注的等级。
