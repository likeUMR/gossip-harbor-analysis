## 证据边界

- 历史页面中的价格曲线、经济拟合、远端模式和玩家分层属于推演或远端缺口，不能当作客户端固定常量。
- `r_order`、`N`、Lucky 和气泡生命周期的规则可作为可复核的分析假设；其动态服务端输入仍标注为 `runtime-pending`。
- “同一棋子出现率变化”只有在控制了库存、母体状态、活动覆盖和订单缺口后才可归因于调控机制。
