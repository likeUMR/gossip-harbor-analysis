# 链升级和 FishNet 具体算法

`SpreadCheckEnergyRatioAndCode` 先把 `energyBoostRatio` 设为最大档。若棋盘提供订单缺口图，就按 `i=0..maxRatio` 检查同链更高等级：目标等级存在缺口，或目标等级库存减订单需求后为正奇数且仍在允许范围时，把比率截断为 `i` 并停止。之后按 `i=1..energyBoostRatio` 重复读取当前代码的 `MergedType`，得到最终代码。服务端 `FishNetProduceSmart` 打开且代码属于 RwaFish 时，再把各等级按 `2^(level-1)` 换算为一级鱼数量；当缺口是一个严格小于满链的二次幂，并且目标等级位于 `origin+1` 到 `origin+3` 范围内，才替换为匹配等级并记录 `FishNetProduceSmart` 场景。

**证据状态**：主判断和字段为 `source-confirmed`；服务器开关、动态活动对象、实际回放时序为 `runtime-pending`。
