# 产出改写与安全边界

产出代码确定前后还有三类会改变最终结果的逻辑：活动可以替换代码或费用，能量增益可以沿合成链升级代码，安全修正会把异常次数限制在配表上限内。它们分别发生在 `GenerateItemCode` 的不同位置，不能合并成一个“加成”字段。

## 贯穿案例：点击食品袋 105

**目的**：制作食物，观察同一次点击怎样从前置检查进入当前页面所解释的分支。

**本页发生什么**：本例先判断活动和增益是否生效，再决定能量和产出是否被改写。Boost 生效时扣除量会按规则调整，免能量活动生效时玩家仍能得到物品但不消耗能量。

### 代入本页的值

假设基础扣能量为 1、活动状态 Started、GeneratorBoost 为 20%。若 Boost 条件满足，扣能量按 `floor(1×1.2)=1`；若 Disco 同时生效且规则要求免能量，则最终扣能量被改为 0。
