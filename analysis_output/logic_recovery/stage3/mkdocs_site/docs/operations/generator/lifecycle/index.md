# 扣除次数与 CD 恢复

产出代码确定后，点击链按“扣次数 → 写入棋盘 → 尝试变换/销毁 → 尝试 CD Buff”的顺序收尾。可恢复母体的剩余次数不足会启动服务器时间计时；一次性母体耗尽则在成功落子后移除自身。
