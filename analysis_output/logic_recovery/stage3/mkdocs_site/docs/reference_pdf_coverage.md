## 仍需区分的证据等级

PDF 是参考分析成果，不等价于当前 APK 的逐函数源码证明。页面已将 PDF 直接给出的数值标为参考快照，将源码能确认的入口、字段和顺序标为源码事实，将缺少真实账号 `FileReplace`、服务器活动 payload、完整亲密度配置或原版运行差分的部分保留为未闭合。这样可以保证“内容不丢失”与“证据不冒充”同时成立。
