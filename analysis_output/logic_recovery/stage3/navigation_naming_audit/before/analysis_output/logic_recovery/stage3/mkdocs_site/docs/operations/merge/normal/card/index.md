# 临时物未生成，再尝试卡片

没有临时物且仍有空位时，按拖入物类型、玩家等级和卡片活动条件判断是否生成卡片。命中后生成当前卡片链的一级物，通知卡片系统，并跳过后续气泡。

## 本机制怎样执行

仍无主副产物且有空位 → 卡片资格与源物等级配置 → 按配置结构处理等级循环 → 概率判定 → 确定卡片链并落子。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：合成备用入口生成卡片

**本例情境：** 卡片活动有效、备用入口符合资格，临时物未生成；这次201合成202有空位。

**判断与目的：** 备用入口资格通过后做一次独立概率判定，命中便生成当前链一级卡片物。

**玩家看到的结果：** 额外得到一件当前卡片链的一级物，202保留；这次不再尝试两类气泡，能量不变。
