# 主副产物之后，独立检查金币

不论主副产物是哪一类，最后再检查是否还有空位以及新物链等级是否达到金币门槛。通过就多生成一枚一级金币。主副产物占满最后空格时，金币不会生成。

## 本机制怎样执行

副产物处理完毕 → 是否还有空位 → 新物等级是否到门槛 → 生成一枚一级金币。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：高阶合成额外生成金币棋子

**本例情境：** 本次合成到第八级208，仍留有空格。

**判断与目的：** 主副产物判断之后另看等级与空间，达到门槛直接发金币棋子。

**玩家看到的结果：** 208旁多一枚一级金币棋子；余额仍100，能量仍10，需要玩家再收取金币棋子。
