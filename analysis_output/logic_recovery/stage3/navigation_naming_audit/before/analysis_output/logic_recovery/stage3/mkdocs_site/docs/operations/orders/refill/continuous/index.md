# 连续订单：按本轮档位逐项抽需求

教程未建单才尝试槽18连续订单。活动状态、进度和界面门控都通过后，按本轮三个需求范围逐项抽物；需求项数来自配置，不另抽普通订单的一二三项权重。

## 内部处理顺序与目的

1. 检查活动、槽位、进度和窗口门控。

2. 按配置范围逐项建立候选，主池失败才用备用；第一项全空用209。

3. 保存重复链状态，再创建固定项数的连续订单。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：三项连续订单

**本例情境：** 连续订单活动有效、窗口已关闭，本轮配置三个需求范围且每项都有合法候选。

**判断与目的：** 前一项成功才挑下一项，按本轮档位逐个抽，不另抽项数。

**玩家看到的结果：** 连续顾客要求203、503、903三件；三项来自活动档位，没有普通随机订单的一二三项轮盘。
