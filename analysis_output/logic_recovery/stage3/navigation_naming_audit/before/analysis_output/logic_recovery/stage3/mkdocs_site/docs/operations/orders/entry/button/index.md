# 按钮门控与入口差异

按钮禁用便结束；普通订单进入数量检查，特殊订单先展示需求。音效在门控之后播放，不能把音效当作交付成功。

## 内部处理顺序与目的

1. 检查按钮是否允许点击；禁用时立即结束。

2. 播放服务音效，再按普通或特殊展示入口分流；声音不代表交付成功。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：按钮允许提交

**本例情境：** 普通订单按钮已开启，棋盘缺的一件204可以从仓库补交。

**判断与目的：** 允许点击后播放服务音效，再检查棋盘需求。

**玩家看到的结果：** 听到服务音效，出现使用仓库204补交的确认窗；金币仍100，物品未扣。
