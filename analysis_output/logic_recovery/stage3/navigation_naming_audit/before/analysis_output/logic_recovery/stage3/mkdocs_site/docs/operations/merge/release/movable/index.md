# 开始拖动与移动资格

先检查拖入棋子能否移动。纸箱、蜘蛛网、锁定物不能作为拖动源；吞噬物还取决于它是否允许点击。首次有效拖动通知教程和界面，之后图像跟随手指，棋盘模型尚未换格。

## 本机制怎样执行

先检查障碍与锁定 → 再检查吞噬物移动许可 → 首次拖动通知 → 图像跟随手指。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：可以拖动的普通食物

**本例情境：** 玩家开始拖动一件未锁定的普通201。

**判断与目的：** 逐项检查限制，没有限制便让图像跟随手指。

**玩家看到的结果：** 201跟随手指，源格的实际棋子尚未移动；没有扣能量。
