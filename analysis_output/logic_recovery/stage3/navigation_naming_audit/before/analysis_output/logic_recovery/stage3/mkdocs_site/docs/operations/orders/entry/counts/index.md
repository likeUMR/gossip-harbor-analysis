# 首次计数只看棋盘

首次判断不含仓库和缓存。它回答“能否直接从棋盘交付”，不是判断所有持有物是否足够。包装物要按实际代码计数，不能把内含类型当裸物品。

## 内部处理顺序与目的

1. 复制棋盘现有代码计数，按精确代码区分裸物与包装物。

2. 首次入口排除仓库、缓存；把结果交给需求核对。

### 场景1：区别棋盘与总持有

**本例情境：** 棋盘有两件203，仓库和缓存都有204，订单需要两件203和一件204。

**判断与目的：** 首次检查只统计棋盘上的精确代码，仓库和缓存都不参与。

**玩家看到的结果：** 虽然仓库和缓存都有204，仍会出现仓库补交提示；缓存不能替代此次材料扣除。
