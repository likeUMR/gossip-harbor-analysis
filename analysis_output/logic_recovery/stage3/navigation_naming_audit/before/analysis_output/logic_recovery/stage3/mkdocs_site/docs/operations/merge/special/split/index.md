# 拆分确认、扣次数与第二落点

剪刀作用普通目标时，将目标拆为两件同链前一级物品，消耗一次剪刀次数。第一件放在目标原格，第二件按周围空位顺序放下；剪刀次数耗尽才删除。

## 本机制怎样执行

确定同链前一级 → 确认与复核资格 → 扣一次剪刀 → 原格生成第一件 → 找空位生成第二件 → 拆分反馈。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：最后一次剪刀拆分

**本例情境：** 玩家确认用只剩一次的剪刀拆分202。

**判断与目的：** 扣剪刀次数，再把目标拆成两件前一级食物；第二件按固定空位顺序放下。

**玩家看到的结果：** 剪刀消失，原202变成两件201，分别在原目标格和原剪刀格；能量不变。
