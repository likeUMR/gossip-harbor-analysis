# 使用状态、内含类型与下一等级

先排除任一已用过的一次性宝箱，再取得两侧用于比较的类型。蜘蛛网和临时物使用内含物代码；普通物提供下一等级。最后排除工厂专用物，确认同类型且仍能升级。

## 本机制怎样执行

排除已用宝箱 → 比较普通/内含类型并取得下一等级 → 排除工厂限制 → 同类型且有下一等级才合成。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：网中201参与合成

**本例情境：** 普通201被拖到网中201上，两者都有可用的下一等级关系。

**判断与目的：** 目标比较的是网里的食物类型，与源相同且能升级，允许合成。

**玩家看到的结果：** 拖入的201与网中201合成202；不需要先把网中物作为拖动源。
