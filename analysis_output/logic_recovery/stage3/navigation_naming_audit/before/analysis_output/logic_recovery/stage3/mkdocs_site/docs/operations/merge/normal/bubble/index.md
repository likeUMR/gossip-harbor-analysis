# 普通气泡：资格、加成、衰减与抽取

前三类没有生成，才考虑普通气泡。先确认空间、功能、基础概率与同类气泡限制；满足特定加成时设为必出，否则按订单需要、高等级气泡存量和未购买天数依次衰减。最后一次独立阈值抽样决定是否落子。

普通配置基础概率为零时不进入正常加成/衰减，也不会因“最低1%”变成有机会。测试强制开关放在这些规则之后，可以覆盖普通限制；棋盘满的最早返回仍挡住它。

## 本机制怎样执行

确认空间与基础资格 → 去除同类重复 → 检查必出加成 → 否则依次衰减 → 测试覆盖 → 阈值随机 → 落子与价格。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

下面分别改变前提，让各条分支实际发生；互斥结果属于不同场景。

### 场景1：订单加成使气泡必出

**本例情境：** 棋盘有空位，前三种副产物未生成；分别设定订单加成、普通衰减或测试强制条件。

**判断与目的：** 新物正好帮助继续制作订单目标，命中订单加成，跳过普通衰减再判定产出。

**玩家看到的结果：** 得到204，旁边还必定出现一枚204气泡；气泡尚未购买，不自动变为第二件可用204。

### 场景2：三种衰减都参与后命中

**本例情境：** 棋盘有空位，前三种副产物未生成；分别设定订单加成、普通衰减或测试强制条件。

**判断与目的：** 订单已够用、高阶气泡存量和登录档依次降低概率，本次独立随机仍命中。

**玩家看到的结果：** 204旁额外出现204气泡；这次在被多项因素压低的机会下仍然命中，已有高阶气泡保留。

### 场景3：概率衰减后的最低机会

**本例情境：** 棋盘有空位，前三种副产物未生成；分别设定订单加成、普通衰减或测试强制条件。

**判断与目的：** 各项衰减压低机会后保留最低机会，本次抽中最低档。

**玩家看到的结果：** 得到204和一枚204气泡；机会很低但没有降为完全不可能，不改变已有高阶气泡。

### 场景4：测试开关强制出气泡

**本例情境：** 棋盘有空位，前三种副产物未生成；分别设定订单加成、普通衰减或测试强制条件。

**判断与目的：** 测试开关在普通规则之后强制命中；仍受最早的满盘返回约束。

**玩家看到的结果：** 测试场景额外出现202气泡；这是调试强制效果，普通玩家基础概率为零的合成不会因此出气泡。
