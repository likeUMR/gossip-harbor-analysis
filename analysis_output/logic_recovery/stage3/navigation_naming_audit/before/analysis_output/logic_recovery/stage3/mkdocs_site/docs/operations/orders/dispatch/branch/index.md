# 分支任务：抽一份减一份直到耗尽

分支奖励的权重表示必须发出的份数，同时影响下一件出现概率。每次抽取减1，全部份数耗尽才结束；棋盘没有空位就进缓存。因此随机改变发放顺序，不改变最终配置总件数。

## 内部处理顺序与目的

1. 完成模型并清除相关链，建立本次有限奖励池。

2. 每轮按剩余份额抽一件，有空位落盘，无空位入缓存。

3. 减掉该件的一份，池耗尽才写完成标记并通知；总件数由配置固定。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：分支奖励有限池全部发完

**本例情境：** 玩家完成槽7的分支任务，六件奖励要发完，但棋盘只有两个空格。

**判断与目的：** 按剩余份额随机一件就减一份，直到所有奖励发完；空间不足的进入缓存。

**玩家看到的结果：** 棋盘收到2402和2405各一件；缓存收到2402一件、2502两件、2503一件；顺序随机，总共六件不会少发。
