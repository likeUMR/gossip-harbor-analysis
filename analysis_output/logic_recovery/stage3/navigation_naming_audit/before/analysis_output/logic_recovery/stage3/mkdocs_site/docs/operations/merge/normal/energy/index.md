# 没有前两种副产物，再尝试能量气泡

能量气泡根据活动时间、当前能量与购买价格门槛选择一条配置。成功时先更新活动下次可触发时间，再尝试落子；没有选到配置才进入普通气泡。它不按普通物品的BubbleChance抽取。

## 本机制怎样执行

仍无主副产物 → 活动时间可触发 → 能量/购买价格选档 → 保存冷却与分组 → 落子；未选档继续普通气泡。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：低能量时生成购买气泡

**本例情境：** 能量偏低、购买价格符合活动档，触发等待已过；临时物和卡片未生成，棋盘有空位。

**判断与目的：** 能量和购买价格同时过门槛，选该档并开始下次触发等待，再落下能量气泡。

**玩家看到的结果：** 202旁出现内含100能量、购买价30宝石的气泡；当前能量仍10，没有自动扣30宝石，等待5分钟后才可能再次触发该机制。
