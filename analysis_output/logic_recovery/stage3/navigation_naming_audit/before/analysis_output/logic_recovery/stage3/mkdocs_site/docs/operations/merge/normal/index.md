# 普通合成：生成新物，再依次结算

特殊作用未接管，才判断普通合成。两边逻辑类型相同且有下一等级、没有已使用宝箱和工厂限制时，消耗两件输入，在目标格创建新物。随后发合成通知、震动四邻格，再进入主棋盘追加结算。

追加顺序为：清购买气泡记忆 → 竞速计分 → 临时棋子 → 卡片 → 能量气泡 → 普通气泡 → 金币 → 同步检查 → 合成日志。临时、卡片、能量气泡、普通气泡相互占用一个主副产物位置；金币独立检查。所有条件都在实际执行时读取，所以同步监听或邻格变化可能影响后续空位与状态。完成后立即返回，不再吞噬或交换。

## 判断与分支（按触发位置）

1. **使用状态、内含类型与下一等级**：先排除任一已用过的一次性宝箱，再取得两侧用于比较的类型。蜘蛛网和临时物使用内含物代码；普通物提供下一等级。最后排除工厂专用物，确认同类型且仍能升级。
2. **移除输入、创建与保存结果**：先删除拖入物，再用新物替换目标。新物按配置重新创建组件和状态，不沿用两件输入的次数、CD或对象身份；普通合成之后才通知其它系统。
3. **合成通知与四邻格震动**：新物已经写入棋盘后，先通知合成，再震动目标周围四个正交邻格。可解锁纸箱会在震动中消除，并可能腾出空间；这些变化发生在副产物判断之前。 合成通知还会让已开启的活动读取源物分数、更新任务，或检查新物解锁；这些响应发生在主棋盘后续副产物判断之前。
4. **清气泡记忆，再处理竞速分数**：普通合成的基础处理完成后，清除上一购买气泡类型，再尝试竞速计分。计分查的是被拖入物类型，不是合成结果；竞速未开启或未入组则跳过，继续副产物。
5. **优先尝试临时棋子**：副产物首先尝试临时物：活动、库存和资源条件通过后，按当前合成链的订单缺口选择帮助物。生成成功会占用本次主副产物名额，跳过卡片和两类气泡；未选出物品才继续。
6. **临时物未生成，再尝试卡片**：没有临时物且仍有空位时，按拖入物类型、玩家等级和卡片活动条件判断是否生成卡片。命中后生成当前卡片链的一级物，通知卡片系统，并跳过后续气泡。
7. **没有前两种副产物，再尝试能量气泡**：能量气泡根据活动时间、当前能量与购买价格门槛选择一条配置。成功时先更新活动下次可触发时间，再尝试落子；没有选到配置才进入普通气泡。它不按普通物品的BubbleChance抽取。
8. **普通气泡：资格、加成、衰减与抽取**：前三类没有生成，才考虑普通气泡。先确认空间、功能、基础概率与同类气泡限制；满足特定加成时设为必出，否则按订单需要、高等级气泡存量和未购买天数依次衰减。最后一次独立阈值抽样决定是否落子。
9. **主副产物之后，独立检查金币**：不论主副产物是哪一类，最后再检查是否还有空位以及新物链等级是否达到金币门槛。通过就多生成一枚一级金币。主副产物占满最后空格时，金币不会生成。
10. **同步检查、合成日志与返回**：所有副产物处理后，检查新物是否需要额外上传，汇总本次合成日志，返回拖拽入口。已经合成成功的拖动不会再进入吞噬或交换；界面释放收尾仍会继续。

## 演示案例

下面分别改变前提，让各条分支实际发生；互斥结果属于不同场景。

### 场景1：网中201参与合成

**本例情境：** 普通201被拖到网中201上，两者都有可用的下一等级关系。

**判断与目的：** 目标比较的是网里的食物类型，与源相同且能升级，允许合成。

**玩家看到的结果：** 拖入的201与网中201合成202；不需要先把网中物作为拖动源。

### 场景2：两件201替换成202

**本例情境：** 两件普通201通过资格检查，准备合成。

**判断与目的：** 先删除两个输入，再在目标格保存并生成下一等级。

**玩家看到的结果：** 两件201变成目标格的一件202，源格空出，能量仍10。

### 场景3：邻格接收合成震动

**本例情境：** 201合成202，目标周围还有三个有物品的正交邻格。

**判断与目的：** 先通知合成，再只震动上下左右邻格。

**玩家看到的结果：** 目标出现202，三个仍有物品的正交邻格收到震动，斜角格没有震动；本例没有额外掉落。

### 场景4：合成推动竞速

**本例情境：** 竞速已开放且玩家已入组，这次201合成202可计竞速分。

**判断与目的：** 合成先清旧气泡购买记忆，再按被拖入物计竞速分。

**玩家看到的结果：** 得到202，竞速从5分升至7分，还差3分达标；没有扣能量。

### 场景5：本次合成达到竞速目标

**本例情境：** 竞速已开放且玩家已入组，这次201合成202可计竞速分。

**判断与目的：** 被拖入物仍计同样分数，本次达到目标并进入达标表现。

**玩家看到的结果：** 202正常生成，竞速达到10分目标，启动达标界面流程。

### 场景6：旧规则帮助订单缺口

**本例情境：** 临时物活动有效，资源与间隔满足，本次201合成202后，同链订单仍缺高阶食物。

**判断与目的：** 资源和间隔都满足，订单仍缺高阶食物，按规则选第一个高于本次结果的临时食物。

**玩家看到的结果：** 202保留，旁边额外出现临时203，帮助继续合成订单所缺的205；本次卡片和两类气泡不再尝试。 本例临时物开始一分钟倒计时。

### 场景7：新规则按等价库存补缺

**本例情境：** 临时物活动有效，资源与间隔满足，本次201合成202后，同链订单仍缺高阶食物。

**判断与目的：** 把低阶库存折算成合成份额，确认高阶需求仍不足，再从可用区间选临时帮助物。

**玩家看到的结果：** 在202旁生成临时203；帮助填补204订单，本次不再抽卡片或气泡。 本例临时物开始一分钟倒计时。

### 场景8：旧模式高级库存阈值触发

**本例情境：** 临时物活动有效，资源与间隔满足，本次201合成202后，同链订单仍缺高阶食物。

**判断与目的：** 高级模式把现有库存折算后确认不足，仍为订单生成帮助物。

**玩家看到的结果：** 202旁出现临时203，帮助继续制作205；高级库存规则通过后仍沿用旧模式的规则列表选物。 本例临时物开始一分钟倒计时。

### 场景9：合成备用入口生成卡片

**本例情境：** 卡片活动有效、备用入口符合资格，临时物未生成；这次201合成202有空位。

**判断与目的：** 备用入口资格通过后做一次独立概率判定，命中便生成当前链一级卡片物。

**玩家看到的结果：** 额外得到一件当前卡片链的一级物，202保留；这次不再尝试两类气泡，能量不变。

### 场景10：低能量时生成购买气泡

**本例情境：** 能量偏低、购买价格符合活动档，触发等待已过；临时物和卡片未生成，棋盘有空位。

**判断与目的：** 能量和购买价格同时过门槛，选该档并开始下次触发等待，再落下能量气泡。

**玩家看到的结果：** 202旁出现内含100能量、购买价30宝石的气泡；当前能量仍10，没有自动扣30宝石，等待5分钟后才可能再次触发该机制。

### 场景11：订单加成使气泡必出

**本例情境：** 棋盘有空位，前三种副产物未生成；分别设定订单加成、普通衰减或测试强制条件。

**判断与目的：** 新物正好帮助继续制作订单目标，命中订单加成，跳过普通衰减再判定产出。

**玩家看到的结果：** 得到204，旁边还必定出现一枚204气泡；气泡尚未购买，不自动变为第二件可用204。

### 场景12：三种衰减都参与后命中

**本例情境：** 棋盘有空位，前三种副产物未生成；分别设定订单加成、普通衰减或测试强制条件。

**判断与目的：** 订单已够用、高阶气泡存量和登录档依次降低概率，本次独立随机仍命中。

**玩家看到的结果：** 204旁额外出现204气泡；这次在被多项因素压低的机会下仍然命中，已有高阶气泡保留。

### 场景13：概率衰减后的最低机会

**本例情境：** 棋盘有空位，前三种副产物未生成；分别设定订单加成、普通衰减或测试强制条件。

**判断与目的：** 各项衰减压低机会后保留最低机会，本次抽中最低档。

**玩家看到的结果：** 得到204和一枚204气泡；机会很低但没有降为完全不可能，不改变已有高阶气泡。

### 场景14：测试开关强制出气泡

**本例情境：** 棋盘有空位，前三种副产物未生成；分别设定订单加成、普通衰减或测试强制条件。

**判断与目的：** 测试开关在普通规则之后强制命中；仍受最早的满盘返回约束。

**玩家看到的结果：** 测试场景额外出现202气泡；这是调试强制效果，普通玩家基础概率为零的合成不会因此出气泡。

### 场景15：高阶合成额外生成金币棋子

**本例情境：** 本次合成到第八级208，仍留有空格。

**判断与目的：** 主副产物判断之后另看等级与空间，达到门槛直接发金币棋子。

**玩家看到的结果：** 208旁多一枚一级金币棋子；余额仍100，能量仍10，需要玩家再收取金币棋子。

### 场景16：正常合成结束并返回

**本例情境：** 201已合成202，本次没有额外副产物，进入结束处理。

**判断与目的：** 完成追加判断后检查同步并记合成日志，返回后不会再吞噬或交换。

**玩家看到的结果：** 棋盘剩目标格202，源格空出，能量不变；同步已提出检查，本例不假设服务器已确认。
