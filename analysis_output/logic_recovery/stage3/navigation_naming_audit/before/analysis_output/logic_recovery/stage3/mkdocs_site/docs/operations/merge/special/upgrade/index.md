# 升级确认与目标替换

升级道具把目标替换为其配置下一等级，消耗一件升级道具。等待确认时道具回原位；取消不执行替换。该路径有合成通知和邻格震动，但不经过普通合成的副产物流水线。

## 本机制怎样执行

目标允许升级 → 打开确认窗并复位道具 → 确认后复核 → 消耗道具并替换目标 → 通知与邻格震动。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：升级202到203

**本例情境：** 玩家把升级道具拖到202，并确认使用。

**判断与目的：** 玩家确认后消耗升级道具，把目标提升一级。

**玩家看到的结果：** 升级道具消失，202变成203；不执行普通合成直接计分和副产物抽取，能量不变。
