# 目标资格与满盘限制

资格由目标配置决定：目标是否允许被升级或拆分。剪刀对普通目标还要求棋盘有空位；两把剪刀合并次数例外，不受这个满盘限制。

## 本机制怎样执行

读取源特殊类型 → 两剪刀直接许可 → 否则核对目标许可 → 拆分再检查空位。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：剪刀获准拆分202

**本例情境：** 玩家用剪刀作用于允许拆分的202，棋盘有空格。

**判断与目的：** 目标允许拆分且有空间，特殊作用先接管拖拽。

**玩家看到的结果：** 出现拆分确认窗，202暂未改变；确认后才能得到两件201。
