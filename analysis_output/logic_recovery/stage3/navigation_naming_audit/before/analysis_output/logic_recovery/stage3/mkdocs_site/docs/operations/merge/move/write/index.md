# 写格、原格复位与位置日志

空位移动沿用原棋子对象，不新建物品或重置母体次数。回到原格时也会清格再写回，但省略移动日志，随后进入移动收尾。

## 本机制怎样执行

目标为空或原格 → 清源格并写目标格 → 按是否真实移动记录日志 → 更新位置。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：把201移入空格

**本例情境：** 玩家把201从原格拖到相邻空格。

**判断与目的：** 空格采用移动路径，沿用原物品，不进行合成。

**玩家看到的结果：** 201从左格移到右格，原格空出；能量仍10，没有新产物。
