# 移除旧单、保存新单与重载

旧单删除时保存上一单需求，供下一次过滤；新单保存需求、类型、头像和独立的Lucky/基准/难度标记。重载从这些值重新构造对象，不应重新随机一份需求。

## 内部处理顺序与目的

1. 删除旧槽记录并保留上一单需求，供下次排除判断。

2. 保存新单的需求、类型、头像、编号与独立标记。

3. 重载按保存字段恢复对象与礼物，不重新随机需求。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：保存与重载保持同一需求

**本例情境：** 槽4旧单移除，新顾客要求203和503，随后重开恢复。

**判断与目的：** 移除旧记录并存历史，新单保存字段；重载按字段恢复，不重抽。

**玩家看到的结果：** 重开后槽4仍是要求203和503的同一订单，旧单两个203的重复记录也保留；不会重开变成另一份需求。
