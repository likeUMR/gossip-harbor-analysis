# 订单难度调整

先按等级、累计难度和付费区间选第一条过滤档。常规等级上限可因库存有富余高阶物而提高，但只作用于符合条件的链；动态候选会被乘50增加机会。

## 内部处理顺序与目的

1. 按等级、累计难度、付费区间找第一条适用过滤档。

2. 检查是否有严格富余的高阶库存，决定哪些链可提高上限。

3. 提高相应候选权重，再按各自链上限筛选；没有富余就保持常规上限。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：富余高阶库存抬高难度

**本例情境：** 玩家档位有效；一条链已有严格富余的第七级库存，另一条链没有。

**判断与目的：** 先选过滤档，有严格富余的高阶物才抬高对应链上限并增强下一等级权重。

**玩家看到的结果：** 新单可以要求链A第8级，帮助使用剩余高阶库存；链B仍只出常规上限内需求。
