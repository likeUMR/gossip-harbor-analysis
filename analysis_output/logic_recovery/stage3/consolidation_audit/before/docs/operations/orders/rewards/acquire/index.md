# 即时奖励发放

奖励逻辑先转换动态奖励，再按类别交给处理器。货币更新资源，普通棋子奖励进入缓存；这不是统一把所有奖励直接放到棋盘。逻辑落账与飞行动画分别执行。

## 内部处理顺序与目的

1. 转换动态奖励并按实际类别分组。

2. 将货币交资源处理器，将棋子交缓存处理器；各组走自己的算法。

3. 逻辑落账先完成，稍后的飞行动画只展示这次结果。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：货币入账与棋子入缓存

**本例情境：** 本次奖励包含8金币和两件204，缓存原为空。

**判断与目的：** 按类别处理，金币变资源，棋子按数量展开入缓存。

**玩家看到的结果：** 金币余额108，缓存增加两件204；棋盘不会凭这一步直接多两件204。
