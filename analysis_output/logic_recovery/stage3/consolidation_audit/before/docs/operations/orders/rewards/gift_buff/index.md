# 礼物与Buff奖励

即时奖励之后才处理礼物，再处理Buff。礼物须亲密度开放；Buff由订单提供的接口决定。它们与最后的金币翻倍是不同调用，不能简单把全部奖励再乘2。

## 内部处理顺序与目的

1. 先检查礼物是否存在、亲密度功能是否开放，再结算礼物。

2. 随后独立检查Buff奖励；它们不自动混入基础奖励快照。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：礼物和Buff分别发放

**本例情境：** 亲密度已开放，本单礼物给3金币，另有Buff给5能量。

**判断与目的：** 先单独发礼物，再单独发Buff，不重复发基础金币。

**玩家看到的结果：** 总共收到11金币和5能量，余额111、能量15；其中礼物3金币与Buff5能量是额外两次结算。
