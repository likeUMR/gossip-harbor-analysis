# 交付动画

材料先在模型中删除，视图再播放飞行动画。普通奖励先表现，相册和礼物稍后表现，顾客最后离开并移除格子。特殊与分支则用各自完成动画。

## 内部处理顺序与目的

1. 先锁定滚动、收集本次扣物对象，播放飞入需求格表现。

2. 按原调度顺序展示普通奖励、烹饪、相册、礼物与宝箱；不重发已落账奖励。

3. 顾客离开后移除旧格、恢复滚动并启动后续提示；特殊与分支使用专用动画。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：材料飞入后顾客离开

**本例情境：** 结算已完成，两件棋盘203和一件仓库204准备播放飞入表现。

**判断与目的：** 先播放三件材料飞入，再展示已到账金币，最后移除顾客并恢复滚动。

**玩家看到的结果：** 看到两件203和仓库204依次完成需求，8金币飞入后顾客离开；余额保持108，不会变116。
