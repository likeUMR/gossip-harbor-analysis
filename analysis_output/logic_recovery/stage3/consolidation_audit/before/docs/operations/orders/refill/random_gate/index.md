# 随机订单资格

随机创建首先选适用于槽位的创建器，再检查等级、批次次数和冷却。次数不足有活动强制补单例外；次数在资格通过时就扣，不能等创建成功后才扣。回归与宝箱顾客可选择不同配置。

## 内部处理顺序与目的

1. 先按槽位选创建器与实际适用配置。

2. 检查等级、批次剩余次数、恢复计时及活动强制补单条件。

3. 资格通过即消耗创建次数，再构造需求；构造失败不退回次数。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：随机次数耗尽与恢复

**本例情境：** 槽4的随机创建额度只剩一次，本例没有活动强制补单。

**判断与目的：** 资格通过立即扣一次；下一次耗尽启动冷却，到期恢复本批次数。

**玩家看到的结果：** 本次允许尝试创建随机单；额度耗尽后等待一小时，到期第一次尝试后还剩4次，不保证构造一定成功。
