# 特殊任务交付

先完成所属订单模型，再取当前特殊配置清理需求链和母体链。清理覆盖棋盘、仓库、缓存；气泡按内含物判断。然后发配置奖励、标记时间线并通知特殊完成。

## 内部处理顺序与目的

1. 先完成所属模型，读取当前任务配置。

2. 按需求链和母体链清理棋盘、仓库与缓存。

3. 刷新需求状态，发配置奖励，写完成时间线并通知专用视图。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：特殊任务完成清链

**本例情境：** 玩家交付任务1，任务要求清理的物品分布在棋盘、仓库和缓存。

**判断与目的：** 完成任务后清理需求链和母体链，再发专用奖励、写任务完成标记。

**玩家看到的结果：** 两条任务相关链从棋盘、仓库和缓存清除；宝石变35、能量变110，任务1完成。
