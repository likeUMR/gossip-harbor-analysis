# 微笑进度

材料扣除前处理订单微笑进度，更新该槽已完成次数并保存。首个普通微笑的提示要等普通链末尾才派发。它不是普通金币奖励，也不等于每张订单固定加1。

## 内部处理顺序与目的

1. 先按活动状态与槽位决定本次增加多少微笑分。

2. 符合主游戏资格才更新活动分数和槽位完成计数、保存并通知。

3. 记录首轮普通微笑资格，提示留到结算尾部触发。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：首个普通微笑订单

**本例情境：** 普通槽1进入微笑活动首轮，本次可加一份微笑进度。

**判断与目的：** 读取本槽微笑奖励，更新活动分数和完成次数，首轮提示留到末尾。

**玩家看到的结果：** 微笑进度变1分，本槽记一次完成；正常交付结算完才出现首个微笑相关提示。
