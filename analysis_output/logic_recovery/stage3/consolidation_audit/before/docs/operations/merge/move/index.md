# 棋子移动

取得目标后，如果目标为空，或者目标就是拖入棋子本身，就走移动路径。先更新格层，再记录位置和刷新加速影响，发移动结束通知，随后返回。因此空格移动不会继续抽副产物，也不会把普通移动当成合成。

原格松手也经过这条路径，位置日志被省略，但移动结束通知仍然发送。

## 判断与分支（按触发位置）

1. **位置更新**：空位移动沿用原棋子对象，不新建物品或重置母体次数。回到原格时也会清格再写回，但省略移动日志，随后进入移动收尾。
2. **加速刷新**：移动可能改变加速棋子的覆盖，所以移动完成后立即刷新计时组件。随后通知移动结束并返回；这次拖动的合成、吞噬和交换均不会执行。

---

## 演示案例

下面分别改变前提，让各条分支实际发生；互斥结果属于不同场景。

### 场景1：把201移入空格

**本例情境：** 玩家把201从原格拖到相邻空格。

**判断与目的：** 空格采用移动路径，沿用原物品，不进行合成。

**玩家看到的结果：** 201从左格移到右格，原格空出；能量仍10，没有新产物。

### 场景2：移动正在计时的母体

**本例情境：** 玩家移动可受加速影响、仍在计时的母体到空格。

**判断与目的：** 母体移动可能改变加速覆盖，因此马上刷新计时组件，再结束移动。

**玩家看到的结果：** 母体到达新格，计时显示按新位置重新核对；本次不合成，也不额外生成物品。
