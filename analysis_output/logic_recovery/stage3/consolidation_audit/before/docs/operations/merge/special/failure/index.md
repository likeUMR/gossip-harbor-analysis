# 道具作用失败

特殊物不满足目标资格时显示原因，但仍继续合成资格检查。弹出确认窗与显示失败提示的控制流不同：前者接管拖拽，后者通常继续。

## 本机制怎样执行

判断失败原因 → 显示提示 → 继续普通合成；提示不等于当前拖动结束。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

---

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：升级被拒后交换

**本例情境：** 升级道具遇到不可升级、但可移动且没有其它作用关系的目标。

**判断与目的：** 显示不能升级的提示，但继续判断后续分派，最终走交换。

**玩家看到的结果：** 没有消耗升级道具，两件物品互换位置；玩家先看到不可升级提示。
