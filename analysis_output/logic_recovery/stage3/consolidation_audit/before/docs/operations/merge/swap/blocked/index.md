# 交换资格

到最后兜底仍不能合成或吞噬，目标被纸箱、蜘蛛网、锁定或吞噬点击限制固定时，不允许交换。拖入物回原格，不消耗双方。

## 本机制怎样执行

前三条路径均未接管 → 目标不能移动 → 源物复位并结束。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：锁定目标拒绝交换

**本例情境：** 201拖到锁定的204，前面的特殊作用、合成和吞噬都不能接管。

**判断与目的：** 最后检查目标能否移动，锁定物不能互换。

**玩家看到的结果：** 201回原格，锁定204保持原位，没有扣能量或合成。
