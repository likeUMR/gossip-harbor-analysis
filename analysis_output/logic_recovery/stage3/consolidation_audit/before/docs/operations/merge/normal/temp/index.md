# 临时棋子产出

副产物首先尝试临时物：活动、库存和资源条件通过后，按当前合成链的订单缺口选择帮助物。生成成功会占用本次主副产物名额，跳过卡片和两类气泡；未选出物品才继续。

## 本机制怎样执行

检查空间、活动和资源 → 按旧/新规则选择订单帮助物 → 保存轮次状态 → 成功落子并排除后续主副产物。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

下面分别改变前提，让各条分支实际发生；互斥结果属于不同场景。

### 场景1：旧规则帮助订单缺口

**本例情境：** 临时物活动有效，资源与间隔满足，本次201合成202后，同链订单仍缺高阶食物。

**判断与目的：** 资源和间隔都满足，订单仍缺高阶食物，按规则选第一个高于本次结果的临时食物。

**玩家看到的结果：** 202保留，旁边额外出现临时203，帮助继续合成订单所缺的205；本次卡片和两类气泡不再尝试。 本例临时物开始一分钟倒计时。

### 场景2：新规则按等价库存补缺

**本例情境：** 临时物活动有效，资源与间隔满足，本次201合成202后，同链订单仍缺高阶食物。

**判断与目的：** 把低阶库存折算成合成份额，确认高阶需求仍不足，再从可用区间选临时帮助物。

**玩家看到的结果：** 在202旁生成临时203；帮助填补204订单，本次不再抽卡片或气泡。 本例临时物开始一分钟倒计时。

### 场景3：旧模式高级库存阈值触发

**本例情境：** 临时物活动有效，资源与间隔满足，本次201合成202后，同链订单仍缺高阶食物。

**判断与目的：** 高级模式把现有库存折算后确认不足，仍为订单生成帮助物。

**玩家看到的结果：** 202旁出现临时203，帮助继续制作205；高级库存规则通过后仍沿用旧模式的规则列表选物。 本例临时物开始一分钟倒计时。
