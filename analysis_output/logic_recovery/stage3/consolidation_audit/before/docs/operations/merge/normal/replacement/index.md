# 合成结果生成

先删除拖入物，再用新物替换目标。新物按配置重新创建组件和状态，不沿用两件输入的次数、CD或对象身份；普通合成之后才通知其它系统。

## 本机制怎样执行

确定新物类型 → 删除拖入物与目标 → 创建并保存结果 → 写目标格并刷新订单。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。

## 演示案例

本例设定本机制所需条件，演示它实际触发后的结果。

### 场景1：两件201替换成202

**本例情境：** 两件普通201通过资格检查，准备合成。

**判断与目的：** 先删除两个输入，再在目标格保存并生成下一等级。

**玩家看到的结果：** 两件201变成目标格的一件202，源格空出，能量仍10。
