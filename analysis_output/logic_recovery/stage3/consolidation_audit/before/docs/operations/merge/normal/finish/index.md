# 合成记录与同步

所有副产物处理后，检查新物是否需要额外上传，汇总本次合成日志，返回拖拽入口。已经合成成功的拖动不会再进入吞噬或交换；界面释放收尾仍会继续。

## 本机制怎样执行

金币检查完毕 → 新物同步检查 → 汇总合成日志 → 返回拖拽分派与视图。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。
