# 演示案例修订记录

本批按 recovery 计划6.8.9修订演示案例，工作记录不进入领导网站。

范围为现有拖拽合成62页、订单提交78页；27＋35个末层节点，89个独立场景。触发条件、输入、计算和结果使用同一案例账本派生四层表达；正文、配置和导航不变。各节点至少一个自身实际发生的场景，拒绝机制以实际拒绝为正例，成功产出机制以产出为正例。互斥活动采用不同场景。

验证结果：140页案例标题和完整场景结果均渲染；案例外原文前缀保持，素材可达；10项关键数值独立复算通过。选取4条具体数值规则分别运行原转换字节码与恢复源码，8/8通过，使用受控依赖。见validation.json。案例分类/数量映射见scenario_ledger.json。修改前文档可在before恢复。
