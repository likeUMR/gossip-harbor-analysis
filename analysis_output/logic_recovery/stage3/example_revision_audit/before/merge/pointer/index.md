# 返回视图：更新选中与释放反馈

模型处理结束后，松手函数仍会完成界面收尾：选中当前结果、刷新信息栏和可交付格，通知释放，清拖动缓存并重启提示。模型提前返回只是结束动作分派，不等于这一整次玩家输入已经不再触发任何界面逻辑。

## 判断与分支（按触发位置）

1. **选择结果、提示与释放通知**：空位移动通常继续选原对象；合成后原对象消失则选目标格结果。最后根据物品是否消失或位置是否变化决定收集提示，发送释放事件并清理拖拽状态。
