# 选择结果、提示与释放通知

空位移动通常继续选原对象；合成后原对象消失则选目标格结果。最后根据物品是否消失或位置是否变化决定收集提示，发送释放事件并清理拖拽状态。

## 本机制怎样执行

根据模型结果选中物品 → 刷新提示与信息栏 → 通知释放 → 清输入状态 → 恢复指示与完成格。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。
