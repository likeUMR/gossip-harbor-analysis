# 普通合成：生成新物，再依次结算

特殊作用未接管，才判断普通合成。两边逻辑类型相同且有下一等级、没有已使用宝箱和工厂限制时，消耗两件输入，在目标格创建新物。随后发合成通知、震动四邻格，再进入主棋盘追加结算。

追加顺序为：清购买气泡记忆 → 竞速计分 → 临时棋子 → 卡片 → 能量气泡 → 普通气泡 → 金币 → 同步检查 → 合成日志。临时、卡片、能量气泡、普通气泡相互占用一个主副产物位置；金币独立检查。所有条件都在实际执行时读取，所以同步监听或邻格变化可能影响后续空位与状态。完成后立即返回，不再吞噬或交换。

## 判断与分支（按触发位置）

1. **使用状态、内含类型与下一等级**：先排除任一已用过的一次性宝箱，再取得两侧用于比较的类型。蜘蛛网和临时物使用内含物代码；普通物提供下一等级。最后排除工厂专用物，确认同类型且仍能升级。
2. **移除输入、创建与保存结果**：先删除拖入物，再用新物替换目标。新物按配置重新创建组件和状态，不沿用两件输入的次数、CD或对象身份；普通合成之后才通知其它系统。
3. **合成通知与四邻格震动**：新物已经写入棋盘后，先通知合成，再震动目标周围四个正交邻格。可解锁纸箱会在震动中消除，并可能腾出空间；这些变化发生在副产物判断之前。 合成通知还会让已开启的活动读取源物分数、更新任务，或检查新物解锁；这些响应发生在主棋盘后续副产物判断之前。
4. **清气泡记忆，再处理竞速分数**：普通合成的基础处理完成后，清除上一购买气泡类型，再尝试竞速计分。计分查的是被拖入物类型，不是合成结果；竞速未开启或未入组则跳过，继续副产物。
5. **优先尝试临时棋子**：副产物首先尝试临时物：活动、库存和资源条件通过后，按当前合成链的订单缺口选择帮助物。生成成功会占用本次主副产物名额，跳过卡片和两类气泡；未选出物品才继续。
6. **临时物未生成，再尝试卡片**：没有临时物且仍有空位时，按拖入物类型、玩家等级和卡片活动条件判断是否生成卡片。命中后生成当前卡片链的一级物，通知卡片系统，并跳过后续气泡。
7. **没有前两种副产物，再尝试能量气泡**：能量气泡根据活动时间、当前能量与购买价格门槛选择一条配置。成功时先更新活动下次可触发时间，再尝试落子；没有选到配置才进入普通气泡。它不按普通物品的BubbleChance抽取。
8. **普通气泡：资格、加成、衰减与抽取**：前三类没有生成，才考虑普通气泡。先确认空间、功能、基础概率与同类气泡限制；满足特定加成时设为必出，否则按订单需要、高等级气泡存量和未购买天数依次衰减。最后一次独立阈值抽样决定是否落子。
9. **主副产物之后，独立检查金币**：不论主副产物是哪一类，最后再检查是否还有空位以及新物链等级是否达到金币门槛。通过就多生成一枚一级金币。主副产物占满最后空格时，金币不会生成。
10. **同步检查、合成日志与返回**：所有副产物处理后，检查新物是否需要额外上传，汇总本次合成日志，返回拖拽入口。已经合成成功的拖动不会再进入吞噬或交换；界面释放收尾仍会继续。

## 贯穿案例：两个201合成202



两个201合成202，源格空出，目标出现202。演示关闭相关活动且邻格无障碍；202基础气泡概率0，链等级2低于默认金币阈值8，所以只得到202，能量不变。

本例不需要抽普通产物池，不扣点击能量。各页面的“对照”会明确改变前提，属于另一条路径；假设倍率、时间、权重与随机值只用于推演，不冒充远端配置。
