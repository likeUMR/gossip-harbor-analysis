# 合成通知与四邻格震动

新物已经写入棋盘后，先通知合成，再震动目标周围四个正交邻格。可解锁纸箱会在震动中消除，并可能腾出空间；这些变化发生在副产物判断之前。 合成通知还会让已开启的活动读取源物分数、更新任务，或检查新物解锁；这些响应发生在主棋盘后续副产物判断之前。

## 本机制怎样执行

新物已写入 → 局部合成通知 → 全局同步响应 → 四邻格组件处理 → 震动通知 → 返回普通追加结算。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。
