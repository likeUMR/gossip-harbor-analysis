# 空格或原格：移动后立即结束

取得目标后，如果目标为空，或者目标就是拖入棋子本身，就走移动路径。先更新格层，再记录位置和刷新加速影响，发移动结束通知，随后返回。因此空格移动不会继续抽副产物，也不会把普通移动当成合成。

原格松手也经过这条路径，位置日志被省略，但移动结束通知仍然发送。

## 判断与分支（按触发位置）

1. **写格、原格复位与位置日志**：空位移动沿用原棋子对象，不新建物品或重置母体次数。回到原格时也会清格再写回，但省略移动日志，随后进入移动收尾。
2. **移动后的加速刷新与通知**：移动可能改变加速棋子的覆盖，所以移动完成后立即刷新计时组件。随后通知移动结束并返回；这次拖动的合成、吞噬和交换均不会执行。

## 贯穿案例：两个201合成202



贯穿合成例的目标格有另一只201，所以跳过移动。把同一拖动的目标改为空格，201直接移过去，类型与能量保持不变。
