# 有目标：先尝试特殊作用

有目标时，先判断拖入物能否对目标产生特殊作用。升级道具和普通剪刀通常弹确认窗；窗口已打开就结束当前拖拽，确认后再复核资格并执行。两把剪刀则直接合并剩余次数。

特殊作用没有接管时继续普通合成。特殊物不能作用会先给失败提示，但提示本身不阻断后续合成、吞噬或交换。

## 判断与分支（按触发位置）

1. **目标资格与满盘限制**：资格由目标配置决定：目标是否允许被升级或拆分。剪刀对普通目标还要求棋盘有空位；两把剪刀合并次数例外，不受这个满盘限制。
2. **升级确认与目标替换**：升级道具把目标替换为其配置下一等级，消耗一件升级道具。等待确认时道具回原位；取消不执行替换。该路径有合成通知和邻格震动，但不经过普通合成的副产物流水线。
3. **两把剪刀合并剩余次数**：目标也是剪刀时，不打开拆分确认窗；两把剪刀合成一把，其次数为两者剩余次数之和。它保留使用量，不把次数恢复成默认值。
4. **拆分确认、扣次数与第二落点**：剪刀作用普通目标时，将目标拆为两件同链前一级物品，消耗一次剪刀次数。第一件放在目标原格，第二件按周围空位顺序放下；剪刀次数耗尽才删除。
5. **失败提示后继续普通分派**：特殊物不满足目标资格时显示原因，但仍继续合成资格检查。弹出确认窗与显示失败提示的控制流不同：前者接管拖拽，后者通常继续。
