# 屏幕落点、吸附与教程限制

松手位置先转为格坐标。刚显示过的合成高亮可以在短时间内把落点吸到对应棋子；教程指定目标不满足时改成非法坐标。它们改变传给模型的落点，不改变普通合成的代码匹配规则。

## 本机制怎样执行

转换松手坐标 → 按近期高亮判断吸附 → 应用教程指定落点 → 交给后续分派。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。
