# 未被接收：拒绝或交换位置

特殊作用、合成与吞噬都没接管，才检查目标可移动性。目标不能移动则拖入物复位；能移动则两件棋子交换位置，保留对象、类型和各自内部状态。最后处理移动加速，返回界面收尾。

## 判断与分支（按触发位置）

1. **不可移动目标：复位结束**：到最后兜底仍不能合成或吞噬，目标被纸箱、蜘蛛网、锁定或吞噬点击限制固定时，不允许交换。拖入物回原格，不消耗双方。
2. **交换写格、订单刷新与计时**：目标可移动时，先交换格层，再分别更新位置和移动日志，刷新加速。棋子对象与组件不重建，因此不会重置母体次数或计时。

## 贯穿案例：两个201合成202



主例合成成功，交换不执行。交换对照把目标改为不同类型的可移动普通物，两件物品互换；能量和物品总量不变。
