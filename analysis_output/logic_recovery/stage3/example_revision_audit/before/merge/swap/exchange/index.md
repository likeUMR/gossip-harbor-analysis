# 交换写格、订单刷新与计时

目标可移动时，先交换格层，再分别更新位置和移动日志，刷新加速。棋子对象与组件不重建，因此不会重置母体次数或计时。

## 本机制怎样执行

目标可移动 → 三次写格完成交换与订单刷新 → 两条日志 → 更新双方位置 → 刷新加速。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。
