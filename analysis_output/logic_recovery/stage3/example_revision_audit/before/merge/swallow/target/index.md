# 创建需求、固定池与拖入资格

目标创建时为最多两项需求选代码和数量。玩家拖入时按完整物品代码检查需求是否尚缺；目标是否允许点击影响移动资格，但不是拖入吞噬的额外门槛。

## 本机制怎样执行

目标创建时选定需求并保存 → 拖入时比对完整代码与剩余数量 → 匹配才接收。

本页说明这一步的条件与结果；下一层给出对应变量、比较、完整配表与数值推演。
