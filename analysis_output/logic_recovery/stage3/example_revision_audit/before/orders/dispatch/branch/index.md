# 分支任务：抽一份减一份直到耗尽

分支奖励的权重表示必须发出的份数，同时影响下一件出现概率。每次抽取减1，全部份数耗尽才结束；棋盘没有空位就进缓存。因此随机改变发放顺序，不改变最终配置总件数。

## 内部处理顺序与目的

1. 完成模型并清除相关链，建立本次有限奖励池。

2. 每轮按剩余份额抽一件，有空位落盘，无空位入缓存。

3. 减掉该件的一份，池耗尽才写完成标记并通知；总件数由配置固定。

## 贯穿案例：203×2与204×1，使用仓库补交

主例不走分支。对照默认槽7，即使没有空位，6件奖励也会通过缓存全部发完。
