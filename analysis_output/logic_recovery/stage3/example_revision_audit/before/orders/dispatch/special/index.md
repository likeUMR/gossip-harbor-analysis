# 特殊任务：完成模型、清整链、发奖

先完成所属订单模型，再取当前特殊配置清理需求链和母体链。清理覆盖棋盘、仓库、缓存；气泡按内含物判断。然后发配置奖励、标记时间线并通知特殊完成。

## 内部处理顺序与目的

1. 先完成所属模型，读取当前任务配置。

2. 按需求链和母体链清理棋盘、仓库与缓存。

3. 刷新需求状态，发配置奖励，写完成时间线并通知专用视图。
