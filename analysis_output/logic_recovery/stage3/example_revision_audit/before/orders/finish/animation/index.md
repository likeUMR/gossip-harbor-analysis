# 扣物飞行、奖励表现与顾客离开

材料先在模型中删除，视图再播放飞行动画。普通奖励先表现，相册和礼物稍后表现，顾客最后离开并移除格子。特殊与分支则用各自完成动画。

## 内部处理顺序与目的

1. 先锁定滚动、收集本次扣物对象，播放飞入需求格表现。

2. 按原调度顺序展示普通奖励、烹饪、相册、礼物与宝箱；不重发已落账奖励。

3. 顾客离开后移除旧格、恢复滚动并启动后续提示；特殊与分支使用专用动画。

---

## 贯穿案例：203×2与204×1，使用仓库补交

模型已扣两件203与仓库204，视图按需求索引播放三件飞入，并展示8金币，顾客离开后恢复滚动。
