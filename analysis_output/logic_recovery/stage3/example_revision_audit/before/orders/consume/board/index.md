# 按棋盘遍历序扣第一件匹配物

逐项找裸代码相同的第一件棋盘物，不按最近距离或等级挑选。同code重复需求会在后一次扫描找到另一实例。

## 内部处理顺序与目的

1. 按需求先后，每一件都从棋盘第一格重新查找。

2. 找到精确代码的第一件就删除，记录原需求索引；找不到才转仓库。
