# 逐件刷新与部分失败边界

每件尝试之后刷新真实数量和其它订单状态。某项没找到也继续处理后面的需求；先发奖再扣物的顺序必须保留，不能用“交付成功”概括所有异常。

## 内部处理顺序与目的

1. 每件尝试后重新计数并刷新订单状态。

2. 材料不足只记错误，前面已发奖励和已扣材料不会回滚，仍继续后续结算。
