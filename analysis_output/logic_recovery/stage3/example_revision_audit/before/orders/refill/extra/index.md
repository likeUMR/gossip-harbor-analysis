# 额外顾客：创建空需求入口并保存活动标记

连续订单未成功才检查槽19额外顾客。它先创建活动入口单，需求为空；不能套用普通随机需求或把空需求解释为已经可以完整领取活动奖励。

## 内部处理顺序与目的

1. 检查槽19、活动剩余时间、已有入口与严格冷却边界。

2. 保存活动入口标记并清除旧计时。

3. 创建空需求入口单，交外层补编号和保存。

---

## 贯穿案例：203×2与204×1，使用仓库补交

主例槽1普通交付跳过这条专用创建；全槽扫描时槽19仅符合活动资格才创建空需求入口。
