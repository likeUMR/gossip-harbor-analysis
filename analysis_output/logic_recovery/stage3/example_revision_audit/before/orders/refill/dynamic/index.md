# 选过滤档，再调整难度上限

先按等级、累计难度和付费区间选第一条过滤档。常规等级上限可因库存有富余高阶物而提高，但只作用于符合条件的链；动态候选会被乘50增加机会。

## 内部处理顺序与目的

1. 按等级、累计难度、付费区间找第一条适用过滤档。

2. 检查是否有严格富余的高阶库存，决定哪些链可提高上限。

3. 提高相应候选权重，再按各自链上限筛选；没有富余就保持常规上限。

---

## 贯穿案例：203×2与204×1，使用仓库补交

本例交付提高累计难度到109，下一单匹配过滤档使用该新值；等级10默认Random1匹配第一档。
