# 先选三个候选，再抽需求项数

普通随机先顺序选第一、第二、第三候选，之后才按权重决定保留几项。因此最终只有一项的单，也可能已经消耗了第二、第三候选选择的随机数与权重状态。

## 内部处理顺序与目的

1. 顺序预选第一、第二、第三候选；每次重建候选并更新重复链记录。

2. 之后才抽需求项数，只保留预选的前几项。

3. 保存重复链历史；未最终保留的预选也可能已经影响随机和历史。
