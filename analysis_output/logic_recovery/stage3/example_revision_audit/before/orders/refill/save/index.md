# 移除旧单、保存新单与重载

旧单删除时保存上一单需求，供下一次过滤；新单保存需求、类型、头像和独立的Lucky/基准/难度标记。重载从这些值重新构造对象，不应重新随机一份需求。

## 内部处理顺序与目的

1. 删除旧槽记录并保留上一单需求，供下次排除判断。

2. 保存新单的需求、类型、头像、编号与独立标记。

3. 重载按保存字段恢复对象与礼物，不重新随机需求。

本例旧需求203;203;204被记为上一单。新单若创建成功，保存其真实需求，之后重载复用已保存需求。
