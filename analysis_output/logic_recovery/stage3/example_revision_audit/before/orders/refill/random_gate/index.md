# 普通随机：槽位、次数与冷却

随机创建首先选适用于槽位的创建器，再检查等级、批次次数和冷却。次数不足有活动强制补单例外；次数在资格通过时就扣，不能等创建成功后才扣。回归与宝箱顾客可选择不同配置。

## 内部处理顺序与目的

1. 先按槽位选创建器与实际适用配置。

2. 检查等级、批次剩余次数、恢复计时及活动强制补单条件。

3. 资格通过即消耗创建次数，再构造需求；构造失败不退回次数。

## 贯穿案例：203×2与204×1，使用仓库补交

默认Random1为UnlockLevel3、Point5、RefreshTime3600；本例等级10通过等级，但是否能补单还需当前points/timer和其它槽状态。
