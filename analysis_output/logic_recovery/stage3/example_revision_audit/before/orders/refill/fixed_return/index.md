# 固定与回归免费订单

固定单按进度的下一Id和槽/等级门槛创建，不随机需求。回归免费单在指定槽与回归时间内取现有较高等级物；计时资格与选物是两个步骤，构造失败也可能已经改计时。

## 内部处理顺序与目的

1. 固定订单先看下一进度、允许槽位和等级，需求直接读表。

2. 固定未成功才可能检查回归免费资格和八小时计时。

3. 回归单从现有较高等级物中均匀选需求，此时不扣物。

主例讲解交付，不假定固定/回归进度。对照固定首条采用原配表需求；回归候选只决定新单需求。
