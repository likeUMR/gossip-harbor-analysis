# 连续订单：按本轮档位逐项抽需求

教程未建单才尝试槽18连续订单。活动状态、进度和界面门控都通过后，按本轮三个需求范围逐项抽物；需求项数来自配置，不另抽普通订单的一二三项权重。

## 内部处理顺序与目的

1. 检查活动、槽位、进度和窗口门控。

2. 按配置范围逐项建立候选，主池失败才用备用；第一项全空用209。

3. 保存重复链状态，再创建固定项数的连续订单。

---

## 贯穿案例：203×2与204×1，使用仓库补交

主例槽1不直接创建连续订单；全槽补位可同时检查槽18。对照第一项两池均空，生成209单需求兜底。
