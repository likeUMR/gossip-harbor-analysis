# 亲密度礼物与Buff奖励

即时奖励之后才处理礼物，再处理Buff。礼物须亲密度开放；Buff由订单提供的接口决定。它们与最后的金币翻倍是不同调用，不能简单把全部奖励再乘2。

## 内部处理顺序与目的

1. 先检查礼物是否存在、亲密度功能是否开放，再结算礼物。

2. 随后独立检查Buff奖励；它们不自动混入基础奖励快照。
