# 奖励落账与棋子进入缓存

奖励逻辑先转换动态奖励，再按类别交给处理器。货币更新资源，普通棋子奖励进入缓存；这不是统一把所有奖励直接放到棋盘。逻辑落账与飞行动画分别执行。

## 内部处理顺序与目的

1. 转换动态奖励并按实际类别分组。

2. 将货币交资源处理器，将棋子交缓存处理器；各组走自己的算法。

3. 逻辑落账先完成，稍后的飞行动画只展示这次结果。
