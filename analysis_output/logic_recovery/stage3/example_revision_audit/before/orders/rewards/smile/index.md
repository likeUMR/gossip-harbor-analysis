# 订单微笑分数与首轮提示

材料扣除前处理订单微笑进度，更新该槽已完成次数并保存。首个普通微笑的提示要等普通链末尾才派发。它不是普通金币奖励，也不等于每张订单固定加1。

## 内部处理顺序与目的

1. 先按活动状态与槽位决定本次增加多少微笑分。

2. 符合主游戏资格才更新活动分数和槽位完成计数、保存并通知。

3. 记录首轮普通微笑资格，提示留到结算尾部触发。
