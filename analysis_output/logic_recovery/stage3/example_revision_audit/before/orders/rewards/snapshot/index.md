# 即时与延迟奖励分离、冻结快照

根据宝箱顾客前缀拆分奖励，普通部分马上发，标记部分稍后发。两份都复制，确保完成消息展示的是提交时的结果。

## 内部处理顺序与目的

1. 按宝箱标记前缀把奖励拆成即时与延迟两份。

2. 复制两份作为交付快照，避免之后重新取奖改变显示结果。

---
