# 按顺序收集活动奖励

活动资格在本次读取时判断，按原调用顺序追加。限时订单提供的相册信息会影响普通相册奖励；宝箱顾客追加的是延迟领取标记。奖励列表顺序不等于分类处理器之间的执行顺序。

## 内部处理顺序与目的

1. 按原调用顺序询问各活动资格，收集本次奖励。

2. 限时订单的相册标记可能阻止重复相册奖励；宝箱标记另留给延迟结算。

3. 最后追加基础奖励，分类处理时不保证不同类别仍按此顺序落账。

## 贯穿案例：203×2与204×1，使用仓库补交

本例所有活动资格关闭，所以不追加活动代币、相册包或宝箱标记；只留下末尾金币。
